# Ruby High 2.0 — large artifacts (NOT in git)

These are excluded from version control (see `.gitignore`) because they are
large and re-creatable. This file records what they were and how to restore them.

## LLM weights — `models/`
- `models/google_gemma-4-E4B-it-Q4_K_M.gguf` (~5.0 GB)
  - Quantized Gemma model used for local NPC agency / generation.
  - Restore: re-download the `Q4_K_M` GGUF for the same Gemma variant from its
    original source (e.g. Hugging Face) into `models/`.

## SAM / depth-segmentation checkpoints — `visual-scene/checkpoints/` (~358 MB)
- Segment-Anything / depth model checkpoints for the visual-scene pipeline.
- See `visual-scene/DEPTH_SEGMENTATION_PIPELINE.md` for which checkpoints are
  expected and where to fetch them.
- Filenames that were present at archive time are listed at the bottom of this file.

## Python virtualenvs — `visual-scene/.venv-sam/`, `visual-scene/.venv-sam312/`
- Recreate with the captured dependency lists:
  ```sh
  cd visual-scene
  python3 -m venv .venv-sam        && ./.venv-sam/bin/pip install -r requirements-sam.txt
  python3 -m venv .venv-sam312     && ./.venv-sam312/bin/pip install -r requirements-sam312.txt
  ```
  (`.venv-sam312` was built against Python 3.14; use a matching interpreter.)

## Build artifacts (regenerated by the build)
- `c/build/`, `c/bin/` — rebuild with the `c/Makefile`.
